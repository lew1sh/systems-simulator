# SystemC Simulator

Проект SystemC симулятора

## Описание

Данный проект представляет собой SystemC симулятор, состоящий из нескольких модулей:
- **Source** - генератор входных сигналов на основе сценария
- **Terminator** - модуль автоматической остановки симуляции по условиям
- **ScenarioLoader** - загрузчик сценариев из файлов

## Структура проекта

```
systemc-simulator/
├── main.cpp                 # Основная функция sc_main
├── source.h                 # Заголовочный файл модуля Source
├── source.cpp               # Реализация модуля Source
├── terminator.h             # Заголовочный файл модуля Terminator
├── terminator.cpp           # Реализация модуля Terminator
├── scenario_loader.h        # Заголовочный файл загрузчика сценариев
├── scenario_loader.cpp      # Реализация загрузчика сценариев
├── Makefile                 # Файл сборки проекта
├── inputs/
│   ├── scenario.txt         # Сценарий входных сигналов
│   └── terminator.txt       # Условия остановки симуляции
└── README.md               # Этот файл
```

## Модули

### Source
Генератор входных сигналов, который подает данные согласно сценарию из файла `inputs/scenario.txt`.


### Terminator
Модуль автоматической остановки симуляции при выполнении заданных условий.


**Функции:**
- Загружает условия остановки из файла `inputs/terminator.txt`
- Проверяет условия на каждом такте
- Останавливает симуляцию при выполнении условий

### ScenarioLoader
Класс для загрузки и управления сценариями симуляции.


### Компиляция
```bash
make
```

### Запуск симуляции
```bash
make run
```

### Очистка
```bash
make clean
```

## Выходные файлы

### VCD файл (wave.vcd)
Генерируется автоматически и содержит временные диаграммы всех отслеживаемых сигналов. 

### Консольный вывод
- Информация о загруженных функциях Terminator
- Изменения входных сигналов
- Проверка условий Terminator
- Результат симуляции
